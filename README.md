# AI×个人品牌收钱营 - 成员目录

一个为「AI×个人品牌收钱营」打造的成员目录网站，帮助大家快速浏览、筛选和链接同频伙伴。

## ✨ 功能特点

- 📱 **响应式设计** - 完美适配手机和电脑
- 🔍 **智能搜索** - 支持按昵称、姓名、学校、城市搜索
- 🏷️ **标签筛选** - 按年级、技能、领域快速筛选
- 👤 **详情展示** - 点击卡片查看完整自我介绍
- 📋 **一键复制** - 快速复制微信号添加好友
- 🎨 **精美界面** - 现代渐变风格，动画交互
